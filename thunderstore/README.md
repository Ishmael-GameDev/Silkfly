# Silkfly

A mod manager for Hollow Knight: Silksong. It installs mods from Thunderstore with their dependencies, sets up the
BepInEx loader in the game folder and keeps your mods in profiles you can switch between and share.

This is a standalone program, not a mod: nothing from this package goes into the game folder.

## Install on Windows

1. Click **Manual Download** on this page.
2. Unzip the downloaded file.
3. Run `Silkfly-Windows-Setup.exe`.

Silkfly is not code-signed yet, so Windows SmartScreen may warn on the first run. Click **More info**, then
**Run anyway**.

After that Silkfly updates itself, you don't need to download it here again.

## Linux and macOS

Get the Linux and macOS versions from the [website](https://ishmael-gamedev.github.io/Silkfly/).
