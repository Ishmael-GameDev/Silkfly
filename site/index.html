Install Silksong mods from Thunderstore in one click. Silkfly sets up the BepInEx loader, installs dependencies and keeps your mods in profiles. Windows, Linux and macOS.

Features
  • Thunderstore catalog with search, filters and categories
  • One-click install with dependencies; update all mods at once
  • Profiles: separate mod sets you can switch and share as a file or a code
  • Play with or without mods
  • Works offline from a cached catalog
  • English and Russian

How to install Silksong mods
  1. Download Silkfly and run it.
  2. It finds the game in Steam or GOG, or you pick the folder, and installs BepInEx.
  3. Click Install on the mods you want.
  4. Press Play with mods.

Windows. If SmartScreen warns, click More info, then Run anyway. Silkfly is not code-signed yet.

macOS. If macOS says the app is damaged, move it to Applications and run xattr -dr com.apple.quarantine /Applications/Silkfly.app in Terminal.

Linux. Run chmod +x Silkfly-Linux.AppImage first.

FAQ

Is Silkfly safe?

Silkfly is open source and every release is built on GitHub from the source code. It is not code-signed yet, so SmartScreen warns about it, and one or two of about 70 antivirus engines on VirusTotal may flag it with machine-learning heuristics.

I already use another mod manager.

If BepInEx is already in the game folder, Silkfly asks first and moves those files to .silkfly-backup, so they can be restored.

Where are my files?

Settings and profiles are in %LOCALAPPDATA%\Silkfly on Windows, ~/.local/share/Silkfly on Linux and ~/Library/Application Support/Silkfly on macOS.

The game hangs on a black screen with mods.

Usually a mod does not support your game version. Check the game with Play without mods, then turn mods off one by one. The log is in BepInEx/LogOutput.log in the profile folder.

Does it work on Steam Deck?

Silkfly has a Linux version that runs in Desktop Mode. The game on Steam Deck runs through Proton, and that setup has not been tested yet.

Is it free?

Yes, Silkfly is free and open source under GPL-3.0.
